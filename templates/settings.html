Settings

Defaults for new scans and renders. Existing jobs keep the settings they started with.

Powers local dialogue and scene-vision classification. Native macOS uses http://127.0.0.1:11434. Leave blank to turn both off. On Umbrel use http://ollama_ollama_1:11434.

qwen3.5:9b is the native Mac default.

qwen3.5:9b accepts images too, so one local model handles both passes.

Automatic uses Apple hardware on macOS and selects 10-bit HEVC for HDR sources.

720p is recommended even for 4K sources. Edit timestamps and final output retain the original timeline and resolution.

The accurate free model downloads once (99 MB), then all frames and results remain on this Mac. CoreML is used when available.

Full verification catches damaged or undecodable frames before the output is accepted.

The original is never changed. A movie named Movie.mkv is returned as Movie.clean.mp4.

Use an absolute path. On macOS this can be a folder under /Volumes or your home directory. It is used only when the destination above is set to “Use the output folder.”
