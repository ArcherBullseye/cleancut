Radarr / Sonarr

Opt a movie or series in with the cleancut tag. SABnzbd downloads normally; CleanCut starts only after Radarr/Sonarr imports the library file.

Configure this page on the CleanCut Mac at localhost, or through an SSH tunnel. API keys stay in a private local configuration file. Blank keys keep existing values.

Otherwise, review the scan in Jobs and choose Render to approve replacement. These jobs replace the original library file, unlike ordinary Library jobs. Full decode verification is mandatory. Detection is imperfect; review is recommended.

Connect after saving

  1. On the CleanCut Mac, start with CLEANCUT_HOST=0.0.0.0 ./macos/run.sh when no jobs are running. Allow access only from your trusted LAN; do not port-forward.
  2. In each Arr app: Settings → Connect → Webhook. Set URL to http://AI-MAC-IP:3000/api/integrations/radarr/webhook or http://AI-MAC-IP:3000/api/integrations/sonarr/webhook.
  3. Use POST, username cleancut, and the shared password below. Set notification tags to cleancut (or your saved tag).
  4. Enable the per-file import/download and upgrade triggers only. Leave Grab, Rename, and Sonarr Import Complete off. Test the webhook, then tag the movies/series you want cleaned.

No SABnzbd script or second trigger is needed. Sonarr tags select a whole series, not individual episodes. Existing library files are not automatically submitted by adding a tag.

Rotating invalidates existing webhook credentials; update both Arr connections. Plain HTTP exposes credentials on the LAN; use a trusted network or a local HTTPS proxy.

Import history and recovery

Originals are backed up temporarily beside the library file. Backups are removed only after verified publication and a confirmed Arr rescan. A crash or NAS disconnect may require “Recover”. Recovery never overwrites a newer library file. Do not rename/move/upgrade a file during publication.
